# meta-mba-agent

Hermes profile distribution for **MBA Copilot**, a DevOps assistant for Meta Business Agents (WhatsApp).

## Start here

- [INSTALL.md](INSTALL.md) — install the profile, choose a model, verify.
- [QUICKSTART.md](QUICKSTART.md) — first chat using the `mba-setup` skill.

## Config

Meta credentials go into `<profile>/workspace/mba/config.json`, created by the `mba-setup` skill. `.env` is deprecated for `META_ACCESS_TOKEN` and `META_ENTITY_ID`.

Identity: `SOUL.md`. Manifest: `distribution.yaml`. Skills: `skills/meta/`.
